# Proyecto Python - Hernandez Kenia & Lindarte Brayan

## Descripción

Proyecto desarrollado en **Python** orientado al manejo de información de **campers** mediante estructuras de datos y archivos **JSON**.

El proyecto reúne lógica de programación y organización de información para resolver una problemática planteada durante la formación.

## Contenido

- Manejo de información de campers.
- Lectura y uso de archivos JSON.
- Estructuras de datos.
- Lógica de programación.
- Organización de información dentro de la aplicación.

## Tecnologías

- **Python**
- **JSON**
